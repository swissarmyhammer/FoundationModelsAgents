title: 'Scheduled agents 4: save the tasks with their session, and restore them'
---
`AgentScheduleStore` protocol (save/load the tasks of one session). `runner.useScheduleStore(_:)` and `runner.restoreSchedules(of:workSite:)` read the tasks of a session after a restart or resume and start their timers: a firing that is past due runs once. Closing the session (`cancelRuns(caller:)`) saves an empty list. The file implementation lives in the host (FoundationModelsACPAgent), because the loading boundary of this package forbids FileManager; the tasks are Codable for it. Tests use an in-memory store. #scheduled-agents
