Operations on the existing `agents` tool, in the style of start/check/cancel agent (`@Operation`, `@Guide`, `CorrectiveOutcome`):

- `schedule agent` (schedule, prompt required; agent default `default`, until, count, name, timeZone optional). The answer always shows the normalized schedule, the time zone, the next 3 firings and the end.
- `list schedules`: per task the id, name, agent, schedule, next firing, short last result, run count, skipped/missed counts, state, end.
- `get schedule`, `cancel schedule`, `pause schedule`, `resume schedule`, `run schedule` (fire now).
- The tool of a session only sees and changes the tasks of its own session.
- An agent that the tool cannot start is refused, except `default`. Depth and folder checks as `start agent`.

Tests through the tool harness. #scheduled-agents
