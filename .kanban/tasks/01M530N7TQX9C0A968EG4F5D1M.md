## Why

The user, 2026-10-16: "any sub-agenting needs to default its session cwd to the cwd of the creator. though i am OK with allowing the CWD to be passed. though this has nothing to do with slash commands, this is just a parameter to starting agents".

^47w1swp added this order for the working folder of a run: request folder → parent folder (child runs only) → `AgentDefinition.folderURL` (agent-folder source only) → `environment.workingDirectory`. Step 3 is wrong. An agent never works in its own folder by default.

## The rule

1. The folder that the start request gives (the `workingDirectory` field of `start agent`, or the `workingDirectory:` argument of the host API). Keep both.
2. Else, the folder of the creator: the session that starts the agent.
   - A run that starts a child: the folder of that run.
   - A host session that is not a run (the root session, or a slash command): the working folder of that session. Find out if the `ToolContext` or the slash `Invocation` gives it. Today, `AgentsToolContext.requestedDirectory(at:)` and the default use `environment.workingDirectory` for a host session.
   - The host API with no folder: `environment.workingDirectory`.
3. Remove the agent-folder default (`isInAgentFolderSource` → `folderURL`) from `AgentRunRequest.workingDirectory(default:)`. An app that wants a root session in the agent folder gives `definition.folderURL` as the request folder.

A slash command is one more way to start an agent, so it obeys the same rule. Its creator is the session, so ^7aafdxr already gives `invocation.workingDirectory`.

## Acceptance

- Update the tests of `RunWorkingDirectoryTests` for the new order. An agent-folder agent that is started with no folder works in the folder of its creator, not in its own folder.
- A test: a `start agent` call from a host session that is not a run uses the folder of that session, if the tool context gives it.
- Update the docs that tell the order (RunningAnAgent.md "The working folder of a run", DelegatingWithTheAgentsTool.md, LoadingTheCatalog.md, docs/skills-and-agents.md) and the doc comments.
- A relative request folder resolves from the folder of the creator.
