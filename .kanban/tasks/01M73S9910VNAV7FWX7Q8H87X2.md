title: 'AgentRegistry.stopWatching(): a public, idempotent stop of the watcher'

## What
ACPAgent ^a84x0wm makes the registry of each session with `watch: true`. A closed session keeps its registry, so its `DotfolderWatcher` runs until the agent is released. Add `public func stopWatching() async` to `AgentRegistry` (Sources/FoundationModelsAgents/Registry/AgentRegistry+Reload.swift). The call stops the watcher and the task of the `layerUpdates` values, and waits for the request task to end. A later build does not start a new watcher. `catalog()` keeps the last catalog. An explicit `reload()` still rebuilds. A second call does nothing. With `watch: false` and no provider, the call does nothing.

## Acceptance Criteria
- [x] After `stopWatching()`, a new AGENT.md in a layer gives no new catalog.
- [x] A second call does nothing; a call before `load()` and a call on `watch: false` do nothing bad.
- [x] A `reload()` after the stop does not start a watcher.
