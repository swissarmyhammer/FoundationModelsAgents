title: AgentsTool adopts the Extras AgentLaunching protocol
---
The Router's delegate hint reads the startable agents of the root session's own `agents` tool through an Extras protocol: `AgentLaunching: Tool { func launchableAgents() async -> [CatalogEntry] }`.

Blocked until that protocol is on Extras main. The Router session (foundationmodelsrouter-75) sends the sha.

- `AgentsTool` conforms. It returns the agents that the tool can start now: catalog definitions filtered by `context.canStart`, so the grant's allowed names apply, its own agent is left out and `enabled: false` agents are left out. It reflects reloads.
- The entries are the same as the ones `AgentCatalogNotices` makes: one-line description, `""` when an agent has none.
- An empty list means the tool can start nothing: an empty catalog, or the messaging-only grant.
- Agreed: no structured marker for a corrective `start agent` call. The Router counts it as a start.
