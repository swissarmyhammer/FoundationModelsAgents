## What
Plan.md §5, the tool part. No `skills:` preload and no `maxTurns` limit here.

- Create `Sources/FoundationModelsAgents/Tools/ToolCatalog.swift`: `public struct ToolCatalog: Sendable` holding `name → @Sendable () -> any Tool`. `register(_ name:_ factory:)`, `names`. Each call of a factory gives a new instance.
- Create `Sources/FoundationModelsAgents/Tools/ToolResolver.swift`: `func resolve(tools: [ToolSpec]?, disallowed: [ToolSpec], catalog: ToolCatalog, agentsTool: (@Sendable ([String]?) async throws -> any Tool)?) async throws -> (tools: [any Tool], diagnostics: [AgentDiagnostic])`. The closure is `async throws` because `AgentsTool.make(context:)` is `async throws`.
  - No `tools` key gives the full catalog.
  - `disallowedTools` applies first, then `tools`.
  - `mcp__<server>`, `mcp__<server>__*`, `mcp__*` are prefix matches.
  - An unknown name is a warning and is skipped. An unknown name in `disallowedTools` is a warning that sorts first in the list.
  - `Agent` or `Agent(a, b)` gives the `agents` tool through the `agentsTool` closure, with the names limited to `a`, `b`. `agents` in the catalog follows the same rules. With no closure, `Agent` is an unknown name.
- Add a function that gives the tool warnings of one definition with no tool made, for `runner.catalog()` in a later task.
