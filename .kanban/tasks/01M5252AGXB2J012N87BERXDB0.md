Only tests. The Router relay sends the answers down.

- An answer at the parent session goes down to the child run that asked, and that run continues with the answer.
- A cancel of the child run ends the question one time at each level.
- `cancelAll()` of the parent ends the question one time at each level.
- `close()` of the parent ends the question one time at each level.

Write fixed-order tests (gates or events). Do not use a time limit, a sleep, a poll or a retry. Do one full run. #elicitation-phase-4
