## What
FoundationModelsACPAgent (task `^b013mv9`, ACPA-1b) must read `tools:` and `disallowedTools:` of the agent of a root session with the same rules as a run. Today `ToolSpec`, `ToolVocabulary`, `ToolSelection` and `AgentsGrant` (`Sources/FoundationModelsAgents/Tools/ToolSelection.swift`, `Sources/FoundationModelsAgents/Definition/ToolSpec.swift`) are internal. Only the raw lists `AgentDefinition.tools` and `disallowedTools` are public.

- Make `AgentsGrant` public (`case all`, `case only([String])`, `allowedNames`). Keep `init(allowed:)` and `merged(with:)` internal unless a public caller needs them.
- New file `Sources/FoundationModelsAgents/Tools/AgentToolSelection.swift`:
  - `public struct AgentToolSelection: Sendable, Equatable` with `names: [String]` (sorted, the same as `ToolSelection.names`), `agentsGrant: AgentsGrant?`, `deniesAgents: Bool`, `diagnostics: [AgentDiagnostic]` (the findings of `ToolSelection`, made into diagnostics with the id and provenance of the definition, in the same order as `ToolResolver` gives them).
  - `extension AgentDefinition { public func toolSelection(over names: [String], hasAgentsTool: Bool) -> AgentToolSelection }`. It parses `tools` and `disallowedTools` with `ToolSpec.parse` and builds one `ToolSelection` over `ToolVocabulary(catalogNames: names, hasAgentsTool:)`. `ToolResolver.resolve` and `ToolResolver.diagnostics(of:catalog:hasAgentsTool:atMaxDepth:)` must use the same code path (no second copy of the rules). The maxDepth warning stays in the run path only.
- Doc comments state the form of the names: a plain name matches a name of `names` exactly (`files`, `shell`, `skills`, …). The entry `agents`, `Agent` or `Agent(a, b)` gives `agentsGrant` only when `hasAgentsTool` is `true`, and never puts `agents` into `names`. An MCP entry `mcp__<server>` matches each name `mcp__<server>__<tool>` of `names`, and the MCP entry for all servers (the form that `ToolSpec.parse` gives `.mcpAll`) matches each name that starts with `mcp__`. Thus the caller gives the MCP tools as `mcp__<server>__<tool>` names. State the exact text of the all-servers entry from `ToolSpec`.
- Add the type to the topics of `Sources/FoundationModelsAgents/FoundationModelsAgents.docc/FoundationModelsAgents.md`.

## Acceptance Criteria
- [ ] `toolSelection(over:hasAgentsTool:)` gives the same `names`, `agentsGrant`, `deniesAgents` and diagnostics as the run path for the same lists and the same catalog names.
- [ ] No `tools` key gives all `names`. `disallowedTools` removes names. An unknown entry gives one warning diagnostic, as for a run.
- [ ] `mcp__srv` matches `mcp__srv__a` and `mcp__srv__b`, but not `mcp__srv2__a`. The all-servers entry matches each `mcp__…` name.
