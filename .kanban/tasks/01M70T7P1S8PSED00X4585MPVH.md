A pure value layer for scheduled agents, with no model.

- `AgentScheduleSpec`: `.cron(CronExpression)` (5 fields: minute hour day-of-month month day-of-week; `*`, lists, ranges, `*/n`, month and weekday names, Sunday as 0 or 7, the Vixie rule that a restricted DOM and DOW match either), `.once(Date)` (ISO 8601 date-time, or a date-time with no zone read in the task time zone), `.interval(seconds)` (`every N minute(s)/hour(s)/day(s)`).
- `next(after:in:)` for each form, in a `TimeZone`.
- A schedule faster than 1 minute is refused, with the reason (each firing is an agent run on one shared model). A one-shot time in the past is refused.
- A text that is none of these gives `.notDirect`, so the caller can ask the normalizer.
- `normalized` text for the answer: the cron text, the ISO time, or `every N minutes`.
